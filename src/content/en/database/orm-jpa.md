# Database → ORM, JPA, Spring Data JPA

## ORM

- Map object ↔ table, reducing repetitive SQL.

## JPA vs Hibernate

- JPA is a specification; Hibernate is a common implementation.

## Spring Data JPA

- Repository pattern, method-name queries, JPQL/native queries, pagination/sorting.

## Notes

- Watch out for N+1, lazy vs eager loading, use fetch join when needed.
