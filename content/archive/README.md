# Archived Content

This directory stores preserved markdown content that is intentionally kept
outside `src/content`, so it is not included in the app's runtime content map.

## Current archived set

- `vi/frontend/agile.md`
- `vi/frontend/code-review.md`
- `vi/frontend/owasp.md`
- `vi/frontend/tdd-bdd.md`
- `vi/frontend/testing.md`

## Why these files were archived

These files were legacy duplicates of topics that already have canonical,
active content under:

- `src/content/vi/other-skills/`
- `src/content/en/other-skills/`

The frontend category metadata does not expose these files in the UI, so
keeping them inside `src/content` would only create hidden duplicate content.
